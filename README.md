# کلوث استور

فروشگاه لباس بچه‌گانه با Next.js، Prisma و زرین‌پال.

## اجرا

```bash
npm install
npx prisma migrate dev
npm run db:seed
npm run dev
```

باز کردن: [http://localhost:3000](http://localhost:3000)

## پنل ادمین

- آدرس: `/admin`
- رمز ورود: مقدار `ADMIN_PASSWORD` در `.env`؛ قبل از انتشار حتماً یک رمز قوی تنظیم کنید.

### ورود گروهی محصولات از Excel

در تب محصولات می‌توان فایل `.xlsx` را پیش‌نمایش و سپس به‌صورت تراکنشی ثبت کرد.

- عنوان‌های پیشنهادی: `نام`، `اسلاگ`، `قیمت (تومان)`، `موجودی`، `دسته`، `گروه سنی`، `جنسیت` و `توضیحات`
- `اسلاگ` و `موجودی` اختیاری‌اند؛ موجودی خالی صفر می‌شود.
- تصویر از Excel وارد نمی‌شود. محصول جدید ابتدا بدون تصویر ثبت می‌شود و مدیر می‌تواند بعداً از فرم ویرایش محصول، فایل JPEG/PNG/WebP را دستی آپلود کند. هنگام به‌روزرسانی محصول تکراری، تصویر فعلی آن حفظ می‌شود.
- برای اندازه فایل و تعداد ردیف‌ها سقف ثابت برنامه‌ای در نظر گرفته نشده است؛ ظرفیت واقعی به حافظه و تنظیمات سرور اجراکننده بستگی دارد.
- برای اسلاگ تکراری می‌توان «بدون تغییر» یا «به‌روزرسانی» را انتخاب کرد.
- اگر حتی یک ردیف خطا داشته باشد، در مرحله ثبت هیچ تغییری در پایگاه داده انجام نمی‌شود.

خروجی Excel پنل‌های فروش دیگر نیز پس از منطبق‌کردن عنوان ستون‌ها با همین ساختار قابل ورود است. برای اتصال مستقیم، تنظیمات از بخش «اتصال فروشگاه‌ها» در پنل مدیریت انجام می‌شود؛ اطلاعات ورود یا توکن‌ها نباید در فایل Excel یا مخزن کد قرار گیرند.

## اتصال ترب، دیجی‌کالا و Instagram

پنل مدیریت سه کارت اتصال دارد و همه تنظیمات از داخل خود پنل انجام می‌شوند؛ متغیر محیطی جداگانه‌ای برای این اتصال‌ها لازم نیست. اطلاعات محرمانه با AES-256-GCM رمزگذاری می‌شوند و کلید محلی به‌صورت خودکار در `prisma/integration-secrets.key` ساخته می‌شود. این فایل در Git نادیده گرفته شده و برای بازیابی اتصال‌ها باید همراه نسخه پشتیبان امن نگهداری شود.

- ترب و دیجی‌کالا: آدرس HTTPS فید/API رسمی فروشنده و توکن احتمالی را یک‌بار داخل کارت همان سرویس وارد کنید و «بررسی و اتصال» را بزنید. این دو سرویس OAuth عمومی مستندی برای ورود مستقیم فروشنده ارائه نکرده‌اند؛ رمز حساب فروشنده در این برنامه دریافت یا ذخیره نمی‌شود.
- Instagram حرفه‌ای: App ID و App Secret برنامه Meta را یک‌بار در پنل وارد کنید، آدرس نمایش‌داده‌شده را در بخش `Valid OAuth Redirect URIs` همان برنامه ثبت کنید و سپس «ورود با Instagram» را بزنید. توکن OAuth به‌صورت خودکار دریافت و رمزگذاری می‌شود.
- اگر قیمت فید ترب یا دیجی‌کالا به ریال است، در پنل گزینه تقسیم قیمت بر ۱۰ را انتخاب کنید.

فید ترب یا دیجی‌کالا باید JSON باشد و آرایه کالاها را در ریشه یا یکی از کلیدهای `products`، `items`، `results` یا `data` برگرداند. نام کالا از `name`/`title`، قیمت از `price`/`sale_price`/`selling_price` و شناسه پایدار از `id`/`product_id`/`sku` خوانده می‌شود. توکن و App Secret هیچ‌گاه به مرورگر برگردانده نمی‌شوند.

برای Instagram از API رسمی حساب‌های Business/Creator و مجوز `instagram_business_basic` استفاده می‌شود. هر پست به‌عنوان محصول با تصویر و توضیح وارد می‌شود؛ چون داده پست قیمت و موجودی فروشگاهی ندارد، این دو مقدار ابتدا صفر هستند و باید از فرم مدیریت تکمیل شوند. وضعیت «متصل شده» فقط بعد از پاسخ موفق سرویس نمایش داده می‌شود. کالاهای همگام‌شده با شناسه سرویس مبدأ ثبت می‌شوند؛ اجرای دوباره رکورد تکراری نمی‌سازد و تصویر دستی مدیر را بازنویسی نمی‌کند.

## درگاه پرداخت

برای اتصال به زرین‌پال سندباکس، `ZARINPAL_MERCHANT_ID` را در `.env` پر کنید.
اگر خالی باشد، چک‌اوت در حالت دمو سفارش را به‌صورت پرداخت‌شده ثبت می‌کند.
